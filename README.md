# Dayline

一款本地优先、离线可用的每日清单 PWA。

## 已实现

- 回车或按钮快速添加任务，标题必填，备注、优先级和日期选填
- 底部固定渐变入口，点击后直接弹出并自动聚焦液态玻璃输入窗
- 添加按钮提交后播放完成动画、关闭悬浮窗并立即生成清单
- 高优先级任务置顶，并用颜色与“重要”标记区分
- 完成项继续保留在今日列表底部并显示删除线和完成时间，也可从总览恢复
- “今日无需完成”状态与恢复
- 未完成任务自动带入今天，并标记“昨天/前天/N 天前”
- 未来日期计划、历史日期查看与完成情况
- 每一天可分别记录工作总结和学习总结，筛选日期时总结显示在清单上方
- 日历按当天清单数量显示颜色深浅
- 每周固定重复任务，可选择每周的一个或多个星期
- 可在单次任务菜单中停止整个重复系列，并保留已完成历史
- 浅色、深色、跟随系统，以及六种主题色
- 今日进度环、状态色和近 7 天任务量/完成度图表
- 整条任务卡片与属性标签使用完整渐变填充，图标统一居中对齐
- 移动端禁用双击和双指缩放，避免输入时自动放大
- 仪表盘、图表、清单和完成状态提供轻量动效
- 只有新增、恢复或状态变更的任务播放清单动画
- 完成任务时播放主题色亮渐变横向填充、勾选绘制、回弹和移入完成区动画，并在支持的设备上触发短震动
- 顶部栏、仪表盘、任务卡、弹层和表单使用透明液态玻璃材质
- Android Chrome 使用 Roboto/Noto Sans 字体、软键盘内容视口和安全区域适配
- Android 系统返回键优先关闭当前悬浮层，而不是直接退出应用
- 减少任务卡与嵌套控件的实时模糊层，保留一致的半透明渐变并优化滚动性能
- 进度环、图表、状态标记和已完成卡片统一跟随主题色，仅完成勾选保留绿色反馈
- 临时状态提示固定在顶部安全区域，不遮挡底部长条添加按钮
- 数据只保存在当前浏览器本地，不请求后端
- PWA 离线缓存、桌面安装与独立图标
- 删除任务后立即生效，不显示撤销提示，不提供编辑功能

## 本地运行

```bash
npm install
npm run icons
npm run dev
```

生产构建：

```bash
npm run build
npm run preview
```

构建结果位于 `dist/`。

## 发布到 GitHub Pages

1. 将当前目录上传为一个 GitHub 仓库。
2. 打开仓库的 `Settings → Pages`。
3. 将 `Build and deployment → Source` 设为 `GitHub Actions`。
4. 推送代码到 `main` 分支，仓库内的工作流会自动构建并发布。

发布地址通常是：

```text
https://<用户名>.github.io/<仓库名>/
```

手机安装方式：

- iPhone：使用 Safari 打开网址，点“分享”，选择“添加到主屏幕”。
- Android：使用 Chrome 打开网址，从浏览器菜单中选择“安装应用”或“添加到主屏幕”。

PWA 安装和离线缓存需要 HTTPS。GitHub Pages 默认提供 HTTPS。

## 数据说明

数据存储在浏览器的本地存储中，与具体域名和浏览器绑定。清理网站数据、卸载浏览器、更换手机或改变发布域名，都可能使原清单无法访问。当前版本按需求不提供账号、云同步和提醒通知。

## 技术

- Vite + TypeScript
- 无 UI 框架，减少启动和执行开销
- Vite PWA / Workbox 静态预缓存
- 全部业务逻辑在浏览器本地完成
